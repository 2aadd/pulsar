# 🌟 Pulsar

A beautiful terminal-based disk usage monitor for Linux.

## Installation

```bash
curl -sSL https://raw.githubusercontent.com/2aadd/pulsar/main/install.sh | bash
```

## Usage

```bash
pulsar
```

## Features
- Real-time CPU and RAM monitoring
- Disk usage with color-coded progress bars
- Top directories by size
- Auto GB/MB formatting

## Requirements
- Python 3.6+
- Linux
